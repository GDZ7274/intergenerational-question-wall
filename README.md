# 【躺倒鸭】解鸭留言墙

这是一个持续运营、移动端优先的线上代际问答产品。用户可以先浏览公开问答墙；需要参与时，从底部“问答”入口选择提问或回答，尚未选择身份的用户再补选“大朋友”或“小朋友”。系统根据身份自动确定内容流向。

## 已确认的产品规则

- 游客无需选择身份即可自由浏览全部已发布便签。
- 参与时先选择“提问”或“回答”；仅在首次真正参与时补选身份，后续直接进入对应流程。
- 大人提问进入小朋友待回答池；大人回答小朋友的问题。
- 小朋友提问进入大人待回答池；小朋友回答大人的问题。
- 问题与回答独立存储，一道问题可以获得多个回答。
- 问答墙以“一问一答”为一张便利贴，详情页聚合同题的其他回答。
- 提问和回答直接在便签模板的书写区输入，输入内容就是提交后的便签排版，不再维护独立预览区。
- 浏览页可直接收藏和分享便签；收藏及便签快照保存在当前浏览器，“我的”中可再次打开或分享，联网时会以公开墙状态校验并清理已下架内容。
- 官方预置内容与用户内容在前台自然混排，不展示来源标签；后台保留来源字段。
- 新问题和回答默认进入待审核队列，管理员通过后才会出现在问题池或问答墙。
- 白名单工作人员可以拍摄实体便签；照片会先在私有区待审，发布后与文字便签混排，支持收藏、分享、举报和下架清理。
- 产品不提供私信或联系方式交换能力。服务端会拦截常见网址、邮箱、大陆手机号和 HTML 尖括号，但这不能替代人工审核，也不能识别所有联系方式变体。

## 原型

`prototype/` 用于承载移动端前台和审核后台。未配置 Supabase 时，前台使用预置内容和浏览器本地数据运行；配置 Supabase schema v4 后，公开浏览读取脱敏视图，提问、回答和举报通过受控 RPC 写入，投稿默认进入审核队列，实体便签媒体由受鉴权 Edge Function 与私有/公开 Storage 管理。

仓库已配置 GitHub Pages 自动发布：推送到 `main` 后，GitHub Actions 会复制 `prototype/`，并使用仓库变量生成线上 Supabase 配置后部署。公开页和后台都设置了 Content Security Policy；前台图标使用项目内的 `prototype/vendor/lucide.min.js`，不依赖第三方 CDN。首次上架和数据库配置步骤见 [GitHub Pages + Supabase 部署说明](docs/DEPLOY.md)。

审核后台入口为 `prototype/admin.html`。管理员通过 Supabase 邮箱 Magic Link 登录，数据库白名单决定权限；`reviewer` 可以审核内容、处置举报、查看日志与运行状态，`owner` 还可以切换运营开关。相关操作通过受限 RPC 执行，重要变更写入不可由浏览器修改的操作记录。

前台仍不等同于完整账号系统：身份选择、匿名会话、草稿、收藏和已看记录保存在当前浏览器，没有账号级自动同步或监护人账号。每次线上问题或回答提交成功后会生成一个 64 位十六进制恢复码，用户可在另一设备手动导入单条投稿、审核状态和最近事件。恢复码是有效期默认 365 天的持有者凭证，任何获得它的人都能查看该投稿并在内容被驳回时修改重投；服务端只保存其 SHA-256 摘要，因此必须立即另存并保持私密。schema v3 之前的投稿不会补发恢复码。

当前原型使用原始 `prototype/assets/wall-scene.png` 作为所有路由共享的固定底图。浏览器会话第一次打开根路径时先完整展示墙面约 2 秒，再叠加高模糊毛玻璃；透明 `hero-overlay.png` 固定在首页与推荐流顶部，欢迎区使用 `landing-duck.png`、提问入口、回答入口和“下滑先看看”。身份、参与、表单、问题池、“我的”和详情弹窗继续使用毛玻璃层保证阅读；前景中的问答便签保持不透明。手机端采用固定视口单张推荐流：上滑下一张、下滑回看、轻点查看详情；浏览页和问题池都不提供内容分类筛选。

推荐流默认排除已经展示过的便签：Cookie 保存去重集合，localStorage 保存有顺序的近期浏览历史，因此刷新后仍可下滑回看；两者都只在当前浏览器生效。`#wall` 是唯一浏览路由，旧的 `#discover` 链接会自动归一到 `#wall`。内容看完后不会自动循环；已打开页面会定时接收新发布内容并剔除下架便签。

线上版提供三档运营状态：暂停投稿时墙和举报仍可用，但提问、回答、重投与问题池关闭；只读模式保留公开墙并关闭所有访客写入与问题池；紧急关闭会隐藏公开墙和问题池并禁止全部访客写入。运营方可附加一条不超过 160 字的公开说明。

问答便签使用两张项目内图片模板：

- `prototype/assets/note-adult-to-child.png`：大人问、小朋友答。
- `prototype/assets/note-child-to-adult.png`：小朋友问、大人答。

移动端以单张完整图片展示，不裁切模板标题、人物、装饰或原图水印；问题与回答分别叠放在图片已有的书写区。提问和回答时，原生输入框直接位于对应书写区，逐字输入不需要截图或双份 DOM 渲染。页面和文字便签分享画布优先复用同目录下的 WebP 优化版本，PNG 保留为原始备份；实体便签仅在用户打开分享面板时读取经审核的公开原图。手机端优先打开系统分享面板，其他浏览器降级为复制链接或图片下载。
