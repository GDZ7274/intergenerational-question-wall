# 双向问答便利贴墙

这是一个持续运营、移动端优先的线上代际问答产品。用户可以先浏览公开问答墙；需要参与时，再选择“大人”或“小朋友”身份，并选择提问或回答。系统根据身份自动确定内容流向。

## 已确认的产品规则

- 游客无需选择身份即可自由浏览全部已发布便签。
- 参与时先选择身份，再选择“提问”或“回答”。
- 大人提问进入小朋友待回答池；大人回答小朋友的问题。
- 小朋友提问进入大人待回答池；小朋友回答大人的问题。
- 问题与回答独立存储，一道问题可以获得多个回答。
- 问答墙以“一问一答”为一张便利贴，详情页聚合同题的其他回答。
- 官方预置内容与用户内容在前台自然混排，不展示来源标签；后台保留来源字段。
- 正式运营时所有公开内容必须通过审核；当前手机内测可使用自动发布的体验模式。产品不提供私信或联系方式交换能力。

## 原型

`prototype/` 用于承载可点击的移动端体验版。未配置 Supabase 时，它使用预置内容和浏览器本地数据运行；配置 Supabase 后，公开问答、问题池、提问、回答和举报可在不同设备之间共享。

仓库已配置 GitHub Pages 自动发布：推送到 `main` 后，GitHub Actions 会复制 `prototype/`，并使用仓库变量生成线上 Supabase 配置后部署。首次上架和数据库配置步骤见 [GitHub Pages + Supabase 部署说明](docs/DEPLOY.md)。

共享数据版仍不等同于完整账号系统。身份选择、匿名会话、草稿、收藏、已看记录以及“我的”页面副本保存在当前浏览器；现阶段没有跨设备个人记录同步、监护人账号或可视化审核后台。

当前原型使用 `prototype/assets/note-wall-background.jpg` 作为所有路由共享的固定底图。首页和推荐流保留较清晰的便签墙轮廓，身份、参与、表单、问题池、“我的”和详情弹窗使用不同透明度的毛玻璃层保证阅读；前景中的问答便签保持不透明。根路径的毛玻璃前景提供“我要提问”“我要回答”和“随便看看”。手机端采用固定视口单张推荐流：上滑下一张、下滑回看、轻点查看详情；浏览页和问题池都不提供内容分类筛选。

推荐流默认排除已经展示过的便签。当前体验版使用 Cookie 保存近期已看 ID，wall 与 discover 共用同一条会话历史；内容看完后不会自动循环。Supabase 共享内容不会改变这一规则，长期已看历史仍未同步到服务端。

问答便签使用两张项目内图片模板：

- `prototype/assets/note-adult-to-child.png`：大人问、小朋友答。
- `prototype/assets/note-child-to-adult.png`：小朋友问、大人答。

移动端以单张完整图片展示，不裁切模板标题、人物、装饰或原图水印；问题与回答分别叠放在图片已有的书写区。页面优先加载同目录下的 WebP 优化版本，PNG 作为原始备份与兼容回退。
