# 问问墙 Design System

> 本文件是全局视觉规则。页面级规则位于 `pages/`，若与本文件冲突，以页面级规则为准。

- 更新日期：2026-08-17
- 产品形态：移动端优先的持续运营问答社区
- 设计方向：Illustrated Paper Templates / Human Q&A Wall

## 1. 设计原则

1. **先读内容，再看装饰**：问题和回答永远是首要视觉对象。
2. **成人与小朋友平等**：不使用低龄卡通、糖果 UI 或幼儿园式配色。
3. **使用真实问答纸模板**：两种方向分别使用指定黄、蓝图片，保留原图纸纹、边框、人物和装饰，不额外堆叠拟物效果。
4. **手机单手完成**：主要动作落在拇指可达区域，触控目标至少 44px。
5. **浏览优先**：打开页面立即看到问答，不做营销 Hero、说明卡或登录拦截。
6. **克制而多彩**：页面底色中性，色彩集中在身份、纸张和状态上，避免单一色系统治页面。

## 2. 视觉语气

- 关键词：真实、温暖、好奇、编辑感、纸张、坦诚、现代中文。
- 参考风格：Anti-Polish / Raw Aesthetic、E-Ink / Paper、Editorial Grid。
- 动效：短促、明确、触觉化；不使用漂浮、弹簧、渐变光晕或循环动画。
- 不采用：Claymorphism、紫色社区模板、Comic 字体、超大圆角、玻璃拟态。

## 3. 色彩

### 基础色

| Token | Hex | 用途 |
| --- | --- | --- |
| `--canvas` | `#F2F4F1` | 页面背景，偏冷中性灰绿 |
| `--surface` | `#FFFDFC` | 顶栏、弹层、表单表面 |
| `--ink` | `#17201B` | 主文字与主操作 |
| `--ink-soft` | `#5C665F` | 次级文字 |
| `--line` | `#CBD1CC` | 分隔线与输入边框 |

### 身份色

| Token | Hex | 用途 |
| --- | --- | --- |
| `--adult` | `#C94F38` | 大人发问、成人身份 |
| `--adult-soft` | `#F5D9D1` | 成人轻背景 |
| `--child` | `#08786D` | 小朋友发问、儿童身份 |
| `--child-soft` | `#D5ECE7` | 小朋友轻背景 |

### 便签模板

| 问答方向 | 图片 | 说明 |
| --- | --- | --- |
| 大人问、小朋友答 | `prototype/assets/note-adult-to-child.png` | 黄色“大同学的小问题”模板 |
| 小朋友问、大人答 | `prototype/assets/note-child-to-adult.png` | 蓝色“小学生的大问题”模板 |

规则：模板颜色与图片标题共同表达方向，整卡仍保留可访问名称，不能只依赖颜色。原图内嵌水印按素材原样保留。

## 4. 字体

- UI、标题、正文：`PingFang SC`, `Noto Sans SC`, `Microsoft YaHei`, sans-serif。
- 模板问题：700 字重，移动端 16-17px，按书写区限制三至四行。
- 模板回答：600 字重，移动端 14-15px，按书写区限制四行；详情仍保留完整内容能力。
- 纸张感来自版式和材质，不使用难读的手写字体承载正文。
- 字距固定为 `0`，不使用负字距或视口宽度缩放字号。

## 5. 形状与层级

- 便签、按钮、输入框最大圆角：8px。
- 图片便签：完整图片 + 轻外阴影，不再叠加 CSS 胶带、折角、纹理或彩色边框。
- 页面区块保持无框；卡片仅用于单张便签、身份选项、问题条目和弹层。
- 不允许卡片套卡片。
- 图片便签不旋转，避免模板印刷文字和叠加正文发虚。

### 阴影

```css
--shadow-note: 0 10px 24px rgba(28, 39, 32, 0.09), 0 2px 0 rgba(64, 55, 34, 0.08);
--shadow-float: 0 14px 36px rgba(24, 33, 27, 0.18);
```

## 6. 移动导航

- 顶栏高度 58-60px，保留品牌、随机浏览和当前身份。
- 底部导航浮在安全区上方 10-12px，左右各留 12px，圆角 8px。
- 三个入口：问答墙、参与、我的。
- 中间“参与”使用主文字色反白或珊瑚色强调；其余为中性图标与文字。
- 编辑和回答表单中隐藏底部导航，使用明确返回动作。

## 7. 组件

### 便签卡

- 模板内已有方向标题、“谁问”和“谁答”标签，页面不重复显示。
- 问题与回答按模板独立的百分比坐标叠放，必须避开人物插画。
- 移动端单列完整展示，使用原始近 `1:1` 比例和 `background-size: contain`，不得裁切外框。
- 黄图回答仅使用左侧区域；蓝图问题仅使用左侧区域。
- 日期和回答数量不覆盖图片，可在详情或图片外的元信息区提供。
- 触摸反馈仅改变阴影和 `translateY(1px)`，持续 100-160ms。

### 表单

- 输入框字号不低于 16px，避免 iOS 自动缩放。
- 标题、计数和隐私提示直接围绕字段排布，不放入说明卡。
- 主要提交按钮全宽或占操作栏 60%以上。
- 便签预览位于表单之后，不阻挡首次输入。

### 详情

- 手机端使用完整页面式 Dialog。
- 问题占首屏上半部，回答用无框分隔列表展开。
- “我也来回答”是唯一高强调动作；收藏、分享、举报为次级工具。

## 8. 动效与反馈

- 普通状态转换：120-180ms。
- 便签按压：`translateY(1px)`，禁止缩放造成布局漂移。
- 提交成功：一次不超过 240ms 的“贴上墙”位移动效。
- 遵循 `prefers-reduced-motion`，关闭非必要动效。
- 错误、成功、审核中必须同时用文字和颜色表达。

## 9. 可访问性

- 正文对比度至少 4.5:1。
- 方向不能只用珊瑚/青绿区分，必须同时显示文字。
- 所有按钮触控尺寸至少 44x44px。
- 图标来自 Lucide，图标按钮必须带可访问名称。
- 键盘焦点使用清晰的 2-3px focus-visible ring。

## 10. 禁止项

- 不使用 emoji 作为 UI 图标。
- 不使用紫色主导、糖果色黏土风、渐变光晕或装饰球。
- 不使用 12px 以上卡片圆角。
- 不使用营销 Hero、功能介绍卡或空洞数据面板。
- 不把官方预置内容做任何前台来源标记。
- 不为儿童回答设置排行榜、热度竞争或私信入口。

## 11. 交付检查

- 360px、390px、430px 无水平滚动。
- 首屏至少露出第一张图片便签的问题与部分回答区。
- 底部导航不遮挡最后一张内容。
- 输入、身份切换、问题池和详情均可单手完成。
- 用户输入按纯文本渲染。
- 焦点、减少动效和弱网状态可用。
